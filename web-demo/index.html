Resolution was selected on validation, then frozen before test-dev evaluation. These comparisons use the same weights and the same 1,610 test-dev images. Changing inference resolution does not retrain the model.

ENGINEERING DECISION

Keep the compact model and increase inference resolution. Overall AP moves from 13.69% to 18.61%; median latency rises from 12.34 to 17.12 ms. That is a measured tradeoff, with no assumed latency budget.

WHAT WE LEARNED

Whole 1280 reaches 21.73% AP at 16.4 ms; tiled 640 reaches 20.47% at 66.1 ms. Tiling has slightly higher small-object average recall: 28.92% versus 28.02%. This tested tile configuration was less efficient; that is not a verdict on every tiling strategy.

04 / ENGINEERING

The work around
the network.

Ultralytics provides YOLO11n and the training engine. This project adds reproducible data handling, controlled inference experiments, scoring, export verification and browser deployment.

  1. 01

    Prepare & audit

    Convert VisDrone annotations, clip boxes, verify images and preserve seeded manifests and hashes. Exact-image overlap checks across splits; related scenes are still possible.

  2. 02

    Train & compare

    Fine-tune COCO-pretrained YOLO11n on 6,471 images, 60 epochs, batch 16, seed 42. Compare resolutions and tiled coordinate mapping with class-aware merging.

  3. 03

    Freeze & evaluate

    Select settings using 548 validation images. Freeze Whole 1280 and confidence 0.30, then evaluate 1,610 test-dev images. AP integration uses confidence 0.001.

  4. 04

    Export & deliver

    Dynamic-shape FP32 ONNX, opset 17. Check ten fixed validation images and three synthetic shapes. Run browser preprocessing, NMS and detections in a dedicated CPU worker.

What the scores mean

Custom COCO-style scoring with a crowd approximation for ignored regions, not official VisDrone challenge scores. NMS IoU 0.7; prediction and evaluator limit 1,000. Small-object bins follow COCO areas in original image coordinates.

What the browser demonstrates

The fine-tuned FP32 model at nominal 1280, with local Canvas preprocessing and ONNX Runtime Web CPU inference. The default confidence is 0.55 for viewing; recorded operating-point results use 0.30. Full test-dev accuracy was measured with PyTorch, not the browser.

Experiment records & export checks ↗

Export checks covered 518 matched detections on ten images, using count/class agreement, box IoU ≥ 0.99 and score difference ≤ 0.001. This sample does not establish full-set browser accuracy.
